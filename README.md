Entry for the [make.fun bounty "Everyday Things, Two Lines, Longer Run"](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

`main.py` (stdlib only, no network) writes exactly two lines to `/output/entry.txt`:
line 1 explains rain to a 10-year-old with a sponge analogy, and line 2 says
what that analogy maps and what it leaves out. See `DRAFTS.md` for the
candidate two-liners and the pairwise reasoning behind the chosen text.

Run it: `python3 main.py` (writes to `$MAKEFUN_OUTPUT_DIR/entry.txt`, default `/output/entry.txt`).
